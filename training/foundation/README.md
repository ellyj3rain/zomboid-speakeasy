# Shared foundation references

Speakeasy owns the source-derived training data, fitted reference weights,
automatic learner evaluation and native export. Each reference preserves its
exact configuration, frozen tokenizer, source-family partition and measured
results. SAO owns native inference, asynchronous scheduling, current-state
revalidation and durable personal learning.

The first [measured reference](r81-reference/README.md) contains academic and
cultural pre-training. Typed task adapters and the personal-learning consumer
remain the next integration dependencies. The independent associative model
keeps its own prediction and outcome history.

# Coordination reference source

This directory contains twenty declared headless situations and the responses
formed from them by the shipped coordination path. The catalogue fixes each
synthetic starting situation and its train, validation or test lineage before
execution. It does not assign an expected response.

For every situation, the runner uses `SAO.Communication` and
`SAO.Perception` to establish proposal reception, calls the production
`SAO.Controller` appraisal, and observes the resulting
`SAO.Organization` evidence boundary. Afflicted and Crossed people retain
separate audit state while both resolve their human shell, activity, capability
and competing pressure through the registered ZAO execution adapter and
`ZAO.Driver`. That condition identity is absent from the model-facing private
appraisal.

`decisions.jsonl` contains four production choices for each currently observed
response: accept, qualify, counter-propose, defer and contest. Every response is
present in each predeclared partition. Decline and withdrawal remain supported
by the enacted process but were not produced by these situations and therefore
are not represented as learned labels.

The manifest hashes the exact Git index blobs after refusing any source whose
working copy differs from its index entry. That keeps the published source
verifiable against immutable SAO and ZAO commits across checkout line-ending
policies.

Reproduce and compare the exact bytes with:

```text
python tools/coordination_scene_dump.py --out artifacts/audits/c81-coordination-reference-source --check
python tools/coordination_scene_dump_test.py
```

The evidence is a controlled production-path run with synthetic starting
conditions. It is not sampled gameplay, a task-label approval, a trained model
or loaded-world acceptance.

automatic model assessment and export. The combined catalogue contains 47
academic books and 16 public-domain cultural and language books. Publisher
archives retain their original bytes, rights evidence, source versions, assets

kindergarten through college. Literature, fables, political and economic writing,
philosophy and historical cultural texts supply additional language and conceptual
material. This collection supplies prerequisite training material. Source
integrity checks and learner performance are separate measurements.

## Reference model

The reference is a pre-normalized causal transformer with token and position
embeddings, masked attention, GELU feed-forward layers and tied output weights.
FP32 supplies the measurement reference. The current 4-layer, 256-wide,
4-attention-head, 256-token candidate is a measured starting point. Its saved
configuration and run receipt establish the exact dimensions of each experiment.

Optimization consumes training-family blocks only. The frozen byte tokenizer
retains its original fitting identity; this route does not fit it on evaluation
sources. Every block retains source, family, passage, offsets and loss masks.
Before release, the complete compact binary and provenance are reconstructed
from admitted source bytes. Training checkpoints and progress remain private
run artifacts. A completed run binds saved weights, optimizer, loss trace and
the original seed baseline to those exact inputs.

Held-out language evaluation samples across every declared evaluation family.
Source-backed assessments additionally report actual answers and automatically
gradable coverage. Missing media, unsupported prose, context truncation and
empty partitions remain visible. A lower text-prediction loss alone does not
establish a completed course or personal mastery.

## Runtime ownership

The trained base supplies a shared language and conceptual substrate under the
existing typed-task architecture. Retrieval, understanding, speaking and grounded
action adapters retain their separate inputs, targets, evaluation and current-state
owners. Ordinary cognition and opposing associative discovery retain independent
predictions and outcomes.

Personal histories and graded learning evidence determine retained knowledge.
Generic source material supplies no unseen county location, object, danger,
native skill, recipe permission or another person's assent. The FP32 tensor
export carries configuration, tokenizer and exact weight inventory. Native
inference parity, the SAO prior consumer and action-grounding integration have
their own executable verification boundaries.

## Operation

Run the Python command-line help from the repository for the exact input paths.
Acquisition, preparation, admission, tokenization and training preserve previous
outputs by creating new directories under `runs/`. PyTorch is loaded only by
reference inference and training; ordinary source/curriculum checks use the
standard Python runtime. Install training dependencies in an isolated environment.
The current measured run uses the isolated local CUDA environment.
